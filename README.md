# Leonardo do Brasil — site

Site estático em HTML e CSS puros (sem dependências).

## Como abrir no VS Code
1. Abra a pasta `leonardo-brasil` no VS Code (Arquivo > Abrir Pasta).
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Clique com o botão direito em `index.html` > **Open with Live Server**.

Também funciona abrindo `index.html` direto no navegador.

## Estrutura
- `index.html` — conteúdo da página
- `css/style.css` — estilos (cores e tema claro/escuro nas variáveis do topo)
- `img/` — coloque aqui a foto real da base e a logo
- `docs/` — PDFs da seção Ética e Compliance

## Para completar
- Trocar a ilustração do heliponto pela foto real (`<div class="photo">` no `index.html`)
- Preencher Onde estamos, LGPD e Ética e Compliance
- As fontes vêm do Google Fonts (precisa de internet)
